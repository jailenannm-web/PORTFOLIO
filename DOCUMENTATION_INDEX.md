## ❓ Frequently Asked Questions

### Q: Where do I start?
**A:** Open `index.html` in your browser, then read **QUICK_START.md**

### Q: How do I configure GitHub API?
**A:** Follow section 1 of **API_CONFIGURATION_GUIDE.md**

### Q: How do I test the contact form?
**A:** Use test case 3.2 in **TESTING_GUIDE.md** with sample data from **DEMO_DATA.md**

### Q: How do I change the location on the map?
**A:** Follow the "Update Location on Map" section in **QUICK_START.md**

### Q: How do I deploy online?
**A:** See "Deploy Online" section in **QUICK_START.md**

### Q: What validation rules apply to forms?
**A:** See "Form Validation Details" in **README.md** or test cases in **TESTING_GUIDE.md**

### Q: How do I view stored form data?
**A:** Use console commands in **DEMO_DATA.md** - "Browser Console Commands"

### Q: What sample data can I use for testing?
**A:** See **DEMO_DATA.md** - has 10+ sample submissions ready to use

### Q: How do I test on mobile?
**A:** See "Test on Mobile" section in **QUICK_START.md**

### Q: Where are the validation error messages?
**A:** See "Form Validation Rules" table in **PROJECT_SUMMARY.md** or **README.md**

### Q: How many tests should I run?
**A:** Use the **TESTING_GUIDE.md** which has 40+ test cases

### Q: Is EmailJS required to work?
**A:** No, it has simulation mode enabled by default. See **API_CONFIGURATION_GUIDE.md**
